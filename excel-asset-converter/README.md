# BK21 물품 현황 변환기

기존 Python GUI 프로그램의 변환 규칙을 브라우저에서 실행하도록 옮긴 프로젝트입니다.

## 사용 방법

1. 웹 페이지에서 `.xls` 또는 `.xlsx` 파일을 선택합니다.
2. **변환 후 다운로드**를 누릅니다.
3. 브라우저가 자동으로 정리된 `.xlsx` 파일을 다운로드합니다.

## 변환 규칙

- 입력 필수 열은 기존 `물품취득원장 정리.py`와 동일합니다.
- 취득일자를 날짜로 변환합니다.
- 내용년수를 정수로 변환합니다.
- 불용가능기간 = 취득일자 + 내용년수
- 취득일자 2020-09-01 이후 데이터만 유지합니다.
- 지정된 17개 열만 출력합니다.
- 출력 파일명: `4단계 두뇌한국(BK)21 물품 현황_YY.MM.DD.xlsx`

## 기술 구성

- 정적 HTML/CSS/JavaScript
- SheetJS (XLSX) 브라우저 라이브러리
- 서버 업로드 없음: Excel 파일은 사용자의 브라우저 안에서만 처리됩니다.
