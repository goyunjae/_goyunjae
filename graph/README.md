# 그래프 생성기

Excel 파일 또는 직접 입력 데이터를 이용해 보고서용 그래프를 생성하는 브라우저 기반 도구입니다.

## 접속 주소

https://goyunjae.github.io/_goyunjae/graph/

## 구조

```text
graph/
├─ index.html
├─ assets/
│  ├─ css/
│  └─ js/
│     ├─ core/
│     ├─ charts/
│     └─ studio/
├─ legacy/
│  └─ python/Graph_2.py
└─ README.md
```

## 특징

- .xlsx, .xls, .csv 업로드 지원
- 직접 입력 표 지원
- 다양한 그래프 유형 및 이미지 저장 지원
- Excel 데이터는 서버로 업로드하지 않고 브라우저 안에서 처리
